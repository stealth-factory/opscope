Every widget here, what it does, and whether it will work on this machine.

Fifteen binaries on a PATH is a list you have to already know. This is the
front door: pick one and it runs, quit it and you are back here.

    opscope [WIDGET] [ARGS...]

Nothing is described twice. The name and the summary are each widget's own
first docstring line, and the note underneath is the paragraph that follows
it - both already maintained, and both checked by widgets/tests/check.rs,
so a widget cannot appear here saying something its own file does not.

Nothing is said here about whether a widget will work. A widget that cannot
run says so itself, on its own screen, in its own words - which is where
somebody who has just tried to start it is already looking, and is the only
place that knows what it actually needs.

Keys: up/down select, enter launches, q quits.

The Python original rescanned its directory on r. This one has no directory
to rescan - the list is compiled in - so there is no recheck key here, and
none is advertised.

ctrl-y and ctrl-e scroll the view a line at a time, as in vim, and the
mouse wheel does the same. They move the pane and never the selection,
which is what the arrows are for.

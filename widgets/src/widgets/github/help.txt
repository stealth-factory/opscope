GitHub delivery metrics across every org and account you can see.

Open pull requests, how many are actually merging, review backlog and issue
counts - for one org, several, or your personal account alongside them.

    github [-n SECONDS] [account ...]

Accounts are org logins, or @me for your own. With none given it uses
`github.accounts` from config, and failing that every org you belong to plus
your personal account.

Open counts - PRs, issues, drafts, review backlog - are point-in-time totals of
whatever is open right now, at any age. Everything else - the merge rate, the
per-day charts and the per-account HELD, R24 and T2D columns - covers the merge
window, which is the N days ending today. HELD is of PRs that closed in that
window, the share that merged. R24 and T2D are of PRs that merged in it: first
human review within 24h, and created-to-merged within 2d. w changes the sample;
the 24h and 2d bars stay put. A page that has not finished is ···, never a
sample drawn as the window.

Credentials: `github.token` in config.json, or $GITHUB_TOKEN. It must be a
*classic* token: a fine-grained one is limited to a single resource owner, so
it cannot span the orgs this board exists to compare. Two scopes - `repo` so search sees private
repositories, and `read:org` to enumerate your orgs. Missing either one does
not fail, it silently undercounts, so the granted scopes are checked and named.
The API is called directly, so the `gh` CLI is not required.

GitHub Enterprise: set `enterprise_hostname` to the web host, for example
`acme.ghe.com`, and requests go to `https://api.acme.ghe.com`; any other host
is treated as Enterprise Server (untested). Or name a variable in
`enterprise_hostname_env` and set the host there; none is read unless named.
The token must come from that host.

Keys: up/down select an account, i shows a legend above the table for
those of the HELD, R24 and T2D columns the pane is wide enough to draw,
and hides it again, r refreshes now, w cycles the window (7/14/30/60/90
days), comma opens settings, q quits.

Press ! to read this widget's notices - warnings that are not about a number on
screen, such as a config file others can read or a recommended tool that is
missing - and dismiss them for this session, for 7 days or for 30. A new notice
shows above the footer for a minute, then as a [!] count in the footer for as
long as it is still true.

ctrl-y and ctrl-e scroll the view a line at a time, as in vim, and the
mouse wheel does the same. They move the pane and never the selection,
which is what the arrows are for.

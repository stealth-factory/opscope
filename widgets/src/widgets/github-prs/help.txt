Watch the pull requests you have to follow up on.

A list of open PRs, and a dashboard for whichever one is selected: checks,
reviews, mergeability, and - when the PR belongs to a stack - the stack it
sits in and the order that stack has to merge in.

    github-prs [-n SECONDS] [search terms ...]

Extra arguments are appended to every source, so `github-prs org:acme`
narrows to one organisation. With none given it uses `github_prs.sources`.
An old `pr` section is still read if `github_prs` is absent, and the pane
says so.

Credentials: `github_prs.token` in config.json, or the variable named by
`token_env` (`$GITHUB_TOKEN` when that key is unset). A classic token with
`repo` and `read:org`.

Keys: up/down select, enter opens a PR, esc goes back, / filters, s cycles the
sort, o reverses it, , opens settings, r refreshes, q quits.

ctrl-y and ctrl-e scroll the view a line at a time, as in vim, and the
mouse wheel does the same. They move the pane and never the selection,
which is what the arrows are for.

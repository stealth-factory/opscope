# `matrix`

[← all widgets](../../../../docs/README.md)

Digital rain. It computes nothing and reports no data; that is deliberate.
Unlike every operational widget, this one is only visual.

## Keys

| Key | Action |
|---|---|

## Configuration

There are no settings. `matrix` intentionally has no data source and no
numbers to configure.

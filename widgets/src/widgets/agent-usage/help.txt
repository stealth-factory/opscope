How much the coding agents on this machine have been used.

One tab per agent, because they do not agree on what usage even means: one
counts tokens, another counts lines it wrote, and several publish nothing at
all outside their own session. A single table would need a shared schema that
does not exist, so each tab shows that agent's own shape - and an agent that
exposes nothing says so rather than showing a plausible zero. Extra Claude
Max profiles from agent_usage.claude_config_dirs get their own tab, titled
with the label the entry names or, failing that, with the directory's own
name. With discovery on, which is the default, an agent's tab appears only
once that agent has been found on this machine. Naming agents and turning
discovery off keeps those tabs up while the first read is still running.

    agent-usage [-n SECONDS]

Most of this is read from local state files. The exception is the remaining
quota, which no agent writes to disk in a current form: Claude, Codex, Cursor
and Copilot each publish one over an endpoint, fetched with the credential
that agent already holds and sent only to that agent's own host. Codex also
publishes how many reset credits are still available, and each credit's
own title and expiry as a date and time in this machine's local zone.
That is separate from the usage-window countdown. Nothing here is inferred
from a number that was not published.

Notion AI is the one remote reading that uses a credential no agent here
holds: Notion publishes no usage API, so its tab asks the endpoints Notion's
web app uses, signed in with a token_v2 cookie you paste into
agent_usage.notion_token or the NOTION_TOKEN_V2 environment variable. It is
sent only to app.notion.com, only while Notion is one of the agents shown,
and never read out of a browser. It is a full sign-in to your Notion
account, so keep config.json chmod 600; the tab warns when it is not.

Devin is the same kind of reading. Its daily and weekly quota, the resets
that came with them, and the extra-usage balance come from app.devin.ai.
The bearer token goes in agent_usage.devin_token or DEVIN_BEARER_TOKEN
(DEVIN_AUTHORIZATION is another name for that variable). The organization
goes in agent_usage.devin_org. Nothing is read from a browser.

Droid (Factory) reads token rate limits, or the older standard and premium
token pools, with a Factory API key. The key goes in
agent_usage.factory_api_key, or FACTORY_API_KEY, or the FACTORY_API_KEY
line in ~/.factory/.env. It is sent only to api.factory.ai, with
app.factory.ai tried once when the API host fails for a reason other than
a rejected key. Nothing is read from a browser.

Keys: left/right or tab switch agent, up/down scroll it, pgup/pgdn by
the page, home/end to either edge, comma opens settings, r refreshes now,
q quits.

ctrl-y and ctrl-e scroll the view a line at a time, as in vim, and the
mouse wheel does the same - which is what up and down do here too.
